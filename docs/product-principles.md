# Product Principles

## What this is

A small mobile game interface. Students use it on their phones while
physically walking through UTN FRRe. They scan QR codes and solve
challenges at each location.

## What this is NOT

- Not a marketing website
- Not a desktop web application
- Not a dashboard or admin panel
- Not a landing page or showcase

## Mobile-first, intentionally narrow

Target viewport: **390 × 844 px**
Supported widths: **320 – 480 px**

On wider screens the same narrow mobile interface is centred.
No alternate desktop layout is introduced at any viewport width.

## Unknown content is never invented

If real faculty information has not been confirmed — room numbers, names,
dates, locations, event facts — **do not invent it**. Use obvious placeholders:

- `[PLACEHOLDER]`
- `[DEMO]`
- Text like: *"El contenido real será definido con el equipo de Tutorías."*

## Copy guidelines

Use short, functional Spanish.

Acceptable:
- "Búsqueda del tesoro"
- "Para comenzar, buscá el QR de inicio en Tutorías."
- "Tu próxima pista"
- "Escanear QR"
- "Respuesta incorrecta"
- "Correcto"
- "Siguiente pista"

Must NOT appear:
- "Explorá, descubrí, conectá"
- "La facu tiene mucho por descubrir"
- "Comienza una aventura inolvidable"
- Any inspirational phrase, slogan, or marketing language

## Interface elements to avoid

- Desktop navigation bars
- Multi-column grids
- Decorative hero sections
- Fake progress timelines
- Excessive card decorations and shadows
- Gradients (except extremely subtle)
- Decorative illustrations in Phase 0
- Fake marketing copy
